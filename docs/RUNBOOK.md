## Daily run (weekday 8:45am ET)

1. D = the previous weekday in ET (on Monday, that's Friday).
2. Composio workbench: make sure `/mnt/files/bali_metrics.py`, `/mnt/files/bali_cover.py`, `/mnt/files/bali_show.py` and `/mnt/files/bali_slack.py` match the project copies. Then exec them in that order (`exec(open('/mnt/files/bali_metrics.py').read())`, and so on); `import datetime as dt, json, threading`. The run takes several minutes (Do Not Contact changes, the duplicate check, sets to a closer since Sep 16, and the show-rate lookups per set lead), longer than the workbench's 180-second cell limit. Run it in a thread: `R={}; TH=threading.Thread(target=lambda: R.update(m=run_show(dt.date(Y,M,D), run_cover(dt.date(Y,M,D))))); TH.start(); TH.join(165)`; while `TH.is_alive()`, call `TH.join(165)` again in the next cell; then `m=R['m']`. If `_q` or another helper looks redefined in a shared workbench, re-exec the files.
3. **Slack cross-check:** read Slack channel `C0C11LAF4DB` with the Slack connector (`slack_read_channel`, `oldest` / `latest` = the start and end of D in ET as Unix timestamps). Keep Bali's messages (`U0BP10N2WSU`) as `[{"user": "U0BP10N2WSU", "ts": "<Message TS>", "text": "<message text with the Close link>"}]`. In the workbench: `m['slack_check']=slack_check(dt.date(Y,M,D), msgs)`. If he posted nothing on D, still run it with `msgs=[]` (it records 0 posted).
